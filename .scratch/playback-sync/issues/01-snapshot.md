# 建立账号级最新播放快照

Type: task
Status: ready-for-agent

## 需求范围

设计账号级最新播放快照及其持久化、过期规则，记录歌曲身份、索引、曲内位置、倍速和更新时间。现有 ConfigManager 的通用存储能力是设计参考，不存在可沿用的播放快照专用接口。

## 验收目标

插件重启后可读取；unknown/超时不会覆盖有效快照；快照超过 30 分钟按过期处理。

## 待确认需求

采样时机、误差基准、stop 位置及特殊歌曲的快照规则已在需求文档中确定。本文仅描述需求，不记录代码进度。


快照数据契约：`song_id` 是唯一恢复依据，必须带 `playlist_id` 和整数 `schema_version`；标题、歌手仅作诊断信息。删除账号时删除快照，新账号标识不继承；按账号串行写入并拒绝旧 revision。不迁移试做存储；纯逻辑测试使用内存存储和 mock 宿主，集成测试使用真实宿主且不写入真实用户存储。
