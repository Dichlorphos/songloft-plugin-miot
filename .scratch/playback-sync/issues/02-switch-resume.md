# 切换设备播放上下文同步

Type: task
Status: ready-for-agent
Blocked by: 01

实现独立设备切换后的播放上下文同步。目标设备成为当前设备后异步加载账号级未过期快照到 PlaylistManager 内存；不自动播放，不新增用户入口或切换 API。现有播放/继续按钮和语音 resume 负责最终起播。

验收：切换不自动出声；目标正在播放时不被打断；正式歌单歌曲按 ID、索引、首曲回退；快照过期或不存在时保留目标原进度；设备组完全不参与；语音 pause/stop/resume 语义分别为保留位置暂停、停止、使用当前上下文继续。

## Progress

- 2026-09-13：需求边界已完成确认并清理重复文档。
- 待实现：目标 PlaylistManager 上下文注入、独立设备判断、现有播放/继续流程接入，以及 AI/普通语音 pause 分流。
