# 切换设备播放上下文同步

Type: task
Status: needs-info
Blocked by: 01

## 需求范围

独立目标设备成为当前设备后，异步保存账号级未过期快照为待播放上下文；不自动播放，不新增用户入口或切换 API。用户明确播放或语音 resume 后才加载并起播。

## 验收目标

切换不自动出声，目标正在播放时不被打断；正式歌单歌曲按 ID、索引、首曲回退；快照过期或不存在时保留目标原上下文；设备组完全不参与。语音 pause 保留位置，stop 保持停止语义；resume 有有效待播放上下文时使用它，否则使用目标原上下文。

## 需求约束

- 切换仅保存待播放上下文，不能触发热重载恢复路径的自动起播。
- 用户明确继续后才加载上下文、生成 URL 并起播，成功后清除待播放上下文。
- 相同待播放上下文去重，切换不覆盖目标活动播放上下文。
- 按账号隔离；设备组成员跳过同步；不同独立目标设备分别保留待播放上下文。
- 旧 AI 返回 `stop` 按停止处理，明确解析为 `pause` 的结果才暂停。
- 设备选择接口即使后台同步失败仍返回成功；快速连续切换按最新 revision 生效。
- 活动上下文在用户继续且准备成功前保持不变；消费失败保留待播放上下文。
