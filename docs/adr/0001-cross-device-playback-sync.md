# ADR-0001：跨设备播放同步采用插件内协调服务

- 状态：提议
- 日期：2026-09-12

## 背景

插件部署在 FNOS Docker 中，播放状态和 URL 生成由插件内部管理。外部脚本无法可靠复用 PlaylistManager 的 seek 偏移、倍速、设备缓存和持久化语义。

## 决策

在插件内增加 PlaybackResumeService。它读取 resolvePlayerStatus 的融合状态，持久化最近播放快照，并仅在用户切换音响或明确点击继续播放时执行一次恢复。取消后台实时镜像和持续轮询同步。

## 取舍

插件内实现可复用现有认证、状态缓存和 URL 构建，减少部署组件；一次性续播的实现和故障边界更清晰，也不会因高频控制造成云端限流或重复起播。代价是不同音响之间不会自动保持实时进度一致。

## 失败处理

unknown、超时或离线只记录日志并保留最近快照；目标推送失败采用退避，不连续重推；目标已有播放时默认不打断。
