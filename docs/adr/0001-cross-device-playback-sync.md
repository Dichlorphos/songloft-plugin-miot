# ADR-0001：跨设备播放同步采用插件内协调服务

- 状态：已被 ADR-0002 取代
- 日期：2026-09-12

## 背景

插件部署在 FNOS Docker 中，播放状态和 URL 生成由插件内部管理。外部脚本无法可靠复用 PlaylistManager 的 seek 偏移、倍速、设备缓存和持久化语义。

## 决策

在插件内增加 PlaybackResumeService。它读取 resolvePlayerStatus 的融合状态，按账号持久化一份最近播放快照。切换音响时只更新当前设备和进度视图，不自动下发播放；用户明确点击播放或继续播放后，才执行一次带 seek 的恢复。取消后台实时镜像和持续轮询同步。

本 ADR 的方案已废弃，不作为当前实现依据。

## 取舍

原方案的取舍记录保留用于历史追溯；当前方案以 ADR-0002 为准。

## 失败处理

历史失败处理记录不再约束当前实现；当前失败处理以 ADR-0002 为准。

## 取代说明

ADR-0002 收敛了需求：不新增“播放最近进度”入口；按账号保存最新播放快照，切换时只形成目标设备的待播放上下文；用户明确继续后才加载并起播。插件启动和热重载仍保留既有恢复行为。
