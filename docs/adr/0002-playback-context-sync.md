# 切换设备播放上下文同步

- 状态：提议
- 日期：2026-09-12

## 决策

按账号保存一条本插件最新成功播放快照。切换设备时只把快照加载到目标 PlaylistManager 的内存上下文，不向设备自动下发播放；用户复用现有播放/继续按钮后才生成 URL 并起播。

## 取舍

不增加新的用户入口、不增加独立切换 API，直接复用设备选择和现有 PlaylistManager 播放流程，降低实现和维护成本。快照只覆盖本插件成功推送的歌曲，避免误同步外部播放。

## 边界决策

本次功能只处理独立设备之间的切换。目标设备属于设备组时，完全沿用现有 GroupCoordinator 和共享 PlaylistManager 行为，不接入跨设备快照同步。

这样可以避免修改设备组成员映射、主设备归属、组内广播和组内持久化逻辑。
